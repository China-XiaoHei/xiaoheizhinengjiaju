# 烧录与控制说明

## 1. STM32

- 工程目录：`STM32`
- 平台：PlatformIO + Arduino
- 串口协议：`57600`

常用命令：

```powershell
cd E:\ST工程\小黑家居\STM32
pio run
pio run -t upload
```

## 2. ESP8266

- 工程目录：`ESP8266`
- 平台：PlatformIO + Arduino
- 与 STM32 串口：`57600`
- WiFi 配网：WiFiManager（首次会开热点）

常用命令：

```powershell
cd E:\ST工程\小黑家居\ESP8266
pio run
pio run -t upload
```

## 3. 云端 MQTT 主题

- 根主题：`xiaohei/aquarium/khome-20260422`
- 状态上报：`.../state`
- 在线状态：`.../availability`
- 指令主题：
  - `.../cmd/light`
  - `.../cmd/pump`
  - `.../cmd/master`
  - `.../cmd/query`

指令 payload：
- `ON`
- `OFF`
- `TOGGLE`

## 4. 本地 HTTP API（ESP8266）

- `GET /api/state`
- `GET /api/control?target=LIGHT&action=ON`
- `GET /api/control?target=PUMP&action=OFF`
- `GET /api/control?target=MASTER&action=TOGGLE`
- `GET /api/control?target=QUERY`

## 5. 安卓 APP

- 工程目录：`小黑APP/FishLightApp`
- 支持两种模式：
  - 云端 MQTT
  - ESP 本地网络（HTTP）
- 状态显示：
  - 鱼缸照明
  - 鱼泵
  - 总开关
  - 设备总状态
  - 最后来源
