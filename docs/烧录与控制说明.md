# 烧录与控制说明

## 1. STM32

- 工程目录：`STM32`
- 平台：PlatformIO + Arduino
- 与 ESP 串口：`57600`（USART1: PA9/PA10）

常用命令：

```powershell
cd E:\ST工程\小黑家居\STM32
pio run
pio run -t upload
```

## 2. ESP8266

- 工程目录：`ESP8266`
- 平台：PlatformIO + Arduino
- 串口对 STM32：`57600`
- 串口策略：硬串口与软串口双通道自动识别
- MQTT Broker：主 `broker-cn.emqx.io`，备 `broker.emqx.io`

常用命令：

```powershell
cd E:\ST工程\小黑家居\ESP8266
pio run
pio run -t upload
```

## 3. MQTT 主题

- 根主题：`xiaohei/aquarium/khome-20260422`
- 状态：`.../state`
- 在线状态：`.../availability`
- 指令：
- `.../cmd/light`
- `.../cmd/pump`
- `.../cmd/master`
- `.../cmd/query`

指令负载：

- `ON`
- `OFF`
- `TOGGLE`

## 4. ESP 本地 API

- `GET /api/state`
- `GET /api/control?target=LIGHT&action=ON`
- `GET /api/control?target=PUMP&action=OFF`
- `GET /api/control?target=MASTER&action=TOGGLE`
- `GET /api/control?target=QUERY`

`/api/state` 增加了诊断字段：

- `serialLink`：`HW_UART / SW_UART / NONE`
- `mqttOnline`：MQTT 是否在线
- `mqttHost`：当前实际连接的 Broker
- `wifiSsid`：当前连接 WiFi 名称

## 5. 安卓 APP

- 工程目录：`小黑APP/FishLightApp`
- 支持两种模式：
- 云端 MQTT
- ESP 本地网络（HTTP）
- 云端状态栏会显示当前 Broker 主机与端口

打包命令：

```powershell
cd E:\ST工程\小黑家居\小黑APP\FishLightApp
.\gradlew.bat clean assembleRelease
```
