# 小黑家居接线表（完整版）

## 1. STM32 引脚定义（从 PA0 开始）

| 功能 | STM32 引脚 | 方向 | 说明 |
|---|---|---|---|
| 总开关输入 | PA0 | 输入（上拉） | 短按切换总开关状态，联动灯和泵 |
| 照明按钮 | PA1 | 输入（上拉） | 短按切换鱼缸照明 |
| 鱼缸照明继电器 | PA2 | 输出 | 接 2 路 5V 继电器 `IN1` |
| 鱼泵继电器 | PA3 | 输出 | 接 2 路 5V 继电器 `IN2` |
| 板载状态灯 | PC13 | 输出 | 设备运行状态 |
| OLED SCL | PB10 | 输出 | 软件 I2C |
| OLED SDA | PB11 | 输出 | 软件 I2C |
| 串口 TX | PA9 (USART1_TX) | 输出 | 发往 ESP8266 |
| 串口 RX | PA10 (USART1_RX) | 输入 | 接收来自 ESP8266 |

## 2. OLED 接线

| OLED 引脚 | 连接 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB10 |
| SDA | PB11 |

## 3. 2 路 5V 继电器模块接线

| 继电器端子 | 连接 |
|---|---|
| VCC | 5V |
| GND | GND（与 STM32/ESP 共地） |
| IN1 | PA2（鱼缸照明） |
| IN2 | PA3（鱼泵） |

负载侧建议：

- 鱼缸灯：`COM1 -> NO1`（默认断电关闭）
- 鱼泵：`COM2 -> NO2`（默认断电关闭）
- 零线按电气规范直接回路，不经过继电器

## 4. ESP8266 接线表（补充完整版）

### 4.1 供电与启动脚（必须）

| ESP8266 引脚 | 连接 | 要求 |
|---|---|---|
| VCC | 稳定 3.3V 电源 | 峰值电流建议 >= 500mA |
| GND | GND | 必须与 STM32、继电器控制地共地 |
| EN / CH_PD | 3.3V | 上拉（常见 10k） |
| RST | 3.3V（上拉） | 可加复位按键到 GND |

Boot 电平要求（ESP-12/NodeMCU）：

- 正常运行：`GPIO0=高`、`GPIO2=高`、`GPIO15=低`
- 烧录模式：`GPIO0=低` 后复位上电

### 4.2 ESP8266 与 STM32 通讯接线（运行时）

当前固件支持“硬串口 + 软串口自动识别”，二选一即可。

方案 A（推荐，硬串口）：

| ESP8266 | STM32 |
|---|---|
| RXD0 (GPIO3) | PA9 (TX) |
| TXD0 (GPIO1) | PA10 (RX) |

方案 B（软串口）：

| ESP8266 | STM32 |
|---|---|
| GPIO4 (Soft RX) | PA9 (TX) |
| GPIO5 (Soft TX) | PA10 (RX) |

注意：

- 只能接一种方案，不要把两种方案同时并线
- 若你使用 `ESP-01/ESP-01S`（没有 GPIO4/5 引脚），请使用方案 A

### 4.3 ESP8266 烧录接线（USB-TTL）

| USB-TTL | ESP8266 |
|---|---|
| 3.3V | VCC |
| GND | GND |
| TXD | RXD0 (GPIO3) |
| RXD | TXD0 (GPIO1) |

烧录步骤关键点：

- 进入烧录前，把 `GPIO0` 拉低并复位
- 烧录完成后，把 `GPIO0` 拉高并再次复位进入运行模式
- 建议烧录时先断开 ESP 与 STM32 的串口连线，防止串口互相干扰

### 4.4 推荐状态自检（上电后）

ESP 成功联网后，访问：

- `http://<ESP_IP>/api/state`

重点看这几个字段：

- `mqttOnline=true`：云端已连接
- `serialLink=HW_UART` 或 `SW_UART`：已识别到 STM32 串口
- `known=true`：ESP 已收到 STM32 状态

如果 `serialLink=NONE`，说明 ESP 到 STM32 串口线或共地仍有问题。

## 5. 物理按键接线

- `PA0` 总开关：一端接 `PA0`，另一端接 `GND`
- `PA1` 照明按钮：一端接 `PA1`，另一端接 `GND`
