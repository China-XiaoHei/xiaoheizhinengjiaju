# 小黑家居接线表

## 1. STM32 引脚定义（从 PA0 开始）

| 功能 | STM32 引脚 | 方向 | 说明 |
|---|---|---|---|
| 总开关输入 | PA0 | 输入（上拉） | 短按切换总开关状态，联动灯和泵 |
| 照明按钮 | PA1 | 输入（上拉） | 短按切换鱼缸照明 |
| 鱼缸照明继电器 | PA2 | 输出 | 接 2 路 5V 继电器 `IN1` |
| 鱼泵继电器 | PA3 | 输出 | 接 2 路 5V 继电器 `IN2` |
| 板载状态灯 | PC13 | 输出 | 设备运行状态 |
| OLED SCL | PB10 | 输出 | 软件 I2C |
| OLED SDA | PB11 | 输出 | 软件 I2C |
| 串口 TX | PA9 (USART1_TX) | 输出 | 发往 ESP8266 |
| 串口 RX | PA10 (USART1_RX) | 输入 | 接收来自 ESP8266 |

## 2. OLED 接线

| OLED 引脚 | 连接 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB10 |
| SDA | PB11 |

## 3. 5V 继电器模块（2 路）

| 继电器端子 | 连接 |
|---|---|
| VCC | 5V |
| GND | GND（与 STM32/ESP 共地） |
| IN1 | PA2（鱼缸照明） |
| IN2 | PA3（鱼泵） |

负载侧建议：

- 鱼缸灯：`COM1 -> NO1`（上电默认断开）
- 鱼泵：`COM2 -> NO2`（上电默认断开）
- 零线按电气规范直接回路，不经过继电器

## 4. ESP8266 与 STM32 串口接线（重点）

当前 ESP 固件支持两种串口通道并自动识别，二选一接线即可：

### 方案 A（推荐）：硬串口

| ESP8266 | STM32 |
|---|---|
| RX (GPIO3) | PA9 (TX) |
| TX (GPIO1) | PA10 (RX) |

### 方案 B：软串口

| ESP8266 | STM32 |
|---|---|
| GPIO4 (RX) | PA9 (TX) |
| GPIO5 (TX) | PA10 (RX) |

注意事项：

- 只接一种通道，不要把两种方案的 `TX` 同时并到 STM32 `PA10`
- STM32、ESP、继电器控制端必须共地
- ESP 供电必须稳定 3.3V（WiFi 发射瞬间电流较大）

## 5. 开关接线

- `PA0` 总开关：一端接 `PA0`，另一端接 `GND`
- `PA1` 照明按钮：一端接 `PA1`，另一端接 `GND`
