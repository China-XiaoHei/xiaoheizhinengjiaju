# 小黑家居鱼缸控制接线表

## 1. STM32 引脚定义（从 PA0 开始）

| 功能 | STM32 引脚 | 方向 | 说明 |
|---|---|---|---|
| 总开关输入 | PA0 | 输入（上拉） | 硬件总开关，开=鱼缸照明+鱼泵同时打开，关=同时关闭 |
| 照明本地按钮 | PA1 | 输入（上拉） | 本地单击切换鱼缸照明（总开关打开时会被总开关优先） |
| 鱼缸照明继电器 | PA2 | 输出 | 控制鱼缸灯继电器 IN1 |
| 鱼泵继电器 | PA3 | 输出 | 控制鱼泵继电器 IN2 |
| 状态灯 | PC13 | 输出 | 板载状态指示 |
| OLED SCL | PB10 | 输出（软件 I2C） | 与原 `家居开发` 项目一致 |
| OLED SDA | PB11 | 输出（软件 I2C） | 与原 `家居开发` 项目一致 |
| ESP8266 RX <- STM32 TX | PA9 (USART1_TX) | 输出 | STM32 发给 ESP8266 |
| ESP8266 TX -> STM32 RX | PA10 (USART1_RX) | 输入 | ESP8266 发给 STM32 |

## 2. OLED 显示屏（同原硬件）

| OLED 引脚 | 连接 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB10 |
| SDA | PB11 |

> 显示内容会持续刷新：鱼缸照明、鱼泵、总开关、网络状态。

## 3. 5V 继电器连接（鱼缸灯 + 鱼泵）

| 继电器模块端子 | 连接 |
|---|---|
| VCC | 5V |
| GND | GND（与 STM32 共地） |
| IN1 | PA2（鱼缸照明） |
| IN2 | PA3（鱼泵） |

负载侧（高压/大电流侧）：
- 鱼缸灯：电源火线串入 `COM1 -> NO1`（默认断电关闭）。
- 鱼泵：电源火线串入 `COM2 -> NO2`（默认断电关闭）。
- 零线按电气规范直接回路连接，不经过继电器。

## 4. ESP8266 连接

| ESP8266 引脚 | 连接 |
|---|---|
| VCC | 3.3V 稳压电源 |
| GND | GND（与 STM32 共地） |
| RX | PA9（STM32 TX） |
| TX | PA10（STM32 RX） |

> 建议使用稳定 3.3V 供电（峰值电流要足够），避免 WiFi 发射导致重启。

## 5. 开关接线建议

- PA0 总开关：一端接 PA0，另一端接 GND（使用内部上拉）。
- PA1 照明按钮：一端接 PA1，另一端接 GND（使用内部上拉）。

## 6. 地线要求

- STM32、ESP8266、继电器控制端必须共地，否则状态会不稳定或无法控制。
