# 接线说明

## STM32

- `PB12`：继电器控制输出
- `PA0`：本地按钮输入，默认内部上拉，按下为低电平
- `PC13`：状态灯输出
- `PA9 / Serial TX`：发送给 ESP8266
- `PA10 / Serial RX`：接收来自 ESP8266

## ESP8266

- `GPIO4`：软件串口 RX，接 STM32 TX
- `GPIO5`：软件串口 TX，接 STM32 RX
- `3.3V`：供电
- `GND`：和 STM32 共地

## 继电器

- `VCC`：5V
- `GND`：GND
- `IN`：STM32 `PB12`

## 注意

- `ESP8266` 的 GPIO 只能接 `3.3V` 逻辑，不能直接接 `5V` 串口
- 继电器是 `5V` 供电，但控制脚建议由 STM32 GPIO 驱动
- 如果你的继电器是低电平触发，可以把 `STM32/platformio.ini` 中的 `RELAY_ACTIVE_HIGH` 改成 `0`
