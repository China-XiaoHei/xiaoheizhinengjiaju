# 小黑家居 - 鱼缸照明与鱼泵远程控制

本项目包含三端程序，已按“本地+云端双控制、状态实时同步”实现：

- `STM32`：继电器控制、物理按钮/总开关、OLED 状态显示
- `ESP8266`：联网、MQTT 云端、HTTP 本地接口、与 STM32 串口同步
- `小黑APP`：安卓端，支持云端 MQTT 与 ESP 本地网络控制

## 主要能力

- APP 分别控制 `鱼缸照明` 和 `鱼泵`
- 物理总开关一键联动灯和泵，且状态回传 APP
- 物理按钮短按触发，状态回传 APP
- OLED 持续显示鱼缸照明/鱼泵/总开关状态
- 云端远程控制与本地局域网控制可并存
