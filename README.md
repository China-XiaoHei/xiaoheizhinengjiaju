# 小黑家居 - 鱼缸照明与鱼泵远程控制

本项目已按最新需求重建，包含三端程序：

- `STM32`：本地继电器控制、按钮/总开关采集、OLED 实时显示
- `ESP8266`：联网、云端 MQTT、局域网 HTTP、与 STM32 串口同步
- `小黑APP`：安卓端，支持云端与本地双模式控制

## 核心能力

- 鱼缸照明与鱼泵分别控制（APP 端单独按钮）
- 硬件总开关同时控制照明+鱼泵
- 本地物理操作状态实时回传 APP
- OLED 持续显示：照明/鱼泵/总开关/网络状态
- 同时支持：
  - 云端 MQTT 控制
  - ESP 本地网络控制
